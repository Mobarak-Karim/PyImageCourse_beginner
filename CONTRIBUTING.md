# Contributing

Small, clear improvements are welcome.

- Keep examples beginner-friendly.
- Prefer official scientific-Python APIs over custom reimplementations.
- Explain *why* a processing step is used.
- Add comments where a beginner is likely to ask “what does this line do?”
- Avoid committing private, patient, unpublished, or proprietary research images.
- If adding an external image, document its source and reuse terms.
- Run the notebook from top to bottom before opening a pull request.
