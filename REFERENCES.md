## Version note

The environment files target `scikit-image>=0.26,<0.27`. The course therefore uses the current 0.26 `max_size` arguments for `remove_small_objects` and `remove_small_holes`, rather than the deprecated `min_size` and `area_threshold` argument names.

## Further help

For image-processing questions, use documentation that matches the installed library version. The scikit-image project also points users to its API reference, examples gallery, and the image.sc community forum.
